# Contributing to Pramaana

There are two ways to contribute: adding analyzed articles to the dataset, and improving the codebase.

---

## Adding an article to the dataset

Articles live in `pramaana_data.py`. Each entry is a dict that was either generated by Pramaana or manually reviewed and verified.

### Before submitting

1. Run the article through your self-hosted instance (see README for setup).
2. Read the generated analysis carefully. If any claim in the analysis is factually wrong, do not submit it — open an issue instead.
3. Verify the URL is publicly accessible (not paywalled, not a 404).
4. Check that the article is not already in `pramaana_data.py`.

### Article requirements

- Published within the last 12 months
- English language
- Covers geopolitics, governance, conflict, or media criticism
- From a named outlet (no anonymous blogs)

### PR format

Add your entry to `pramaana_data.py` following the existing structure. Set the `region` field:

| Value | When to use |
|-------|-------------|
| `"india"` | India-specific coverage, Indian outlets |
| `"global"` | International/multilateral stories |
| `"official"` | Government/institutional communication (excluded from leaderboard) |

Open a PR with the title: `dataset: add [outlet] — [article headline]`

In the PR description, include:
- Why you chose this article
- Whether the generated score seems accurate, and any notes on edge cases

---

## Code contributions

Standard flow: fork → branch → PR. Keep PRs focused — one thing per PR.

For significant changes (new scoring dimensions, new API routes, frontend redesign), open an issue first to discuss before building.

### Running locally

```bash
git clone https://github.com/rachit-mishra/pramaana
cd pramaana
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # add your ANTHROPIC_API_KEY
uvicorn main:app --reload
```

Open http://localhost:8000.

### Self-hosting with Docker

```bash
cp .env.example .env   # add your ANTHROPIC_API_KEY
docker-compose up
```

## Reporting a score you believe is wrong

Open an issue using the **Score dispute** template. Include:
1. The article URL
2. The dimension(s) you think are wrong
3. Specific evidence — links, primary sources, not just disagreement with the conclusion

Score disputes with evidence will be reviewed and the dataset updated if warranted.
